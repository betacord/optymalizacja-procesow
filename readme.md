## Pełne treści przedmiotu 

1. Wstęp do modelowania matematycznego
    1. 4-stopniowy proces optymalizacji modeli matematycznych
    2. Matematyczna formalizacja modeli
    3. Definicja modeli matematycznych w sposób uogólniony
2. Wstęp do optymalizacji praktycznej
    1. Poszukiwanie optimum za pomocą naiwnego przeszukiwania (ang. brute-force) z jedną pętlą.
    2. Dlaczego dodanie drugiego wymiaru (podwójna pętla) znacząco zwiększa złożoność obliczeniową?
    3. Optymalizacja w praktyce, czyli zastosowanie dedykowanych algorytmów poszukujących rozwiązania.
    4. Optymalizacja rozmyta, gdzie cel jest "nieostry".
    5. Reprezentacja procesów chemicznych w języku Python.
    6. Optymalizacja procesów chemicznych.
3. Programowanie matematyczne
    1. Definicja i zakres zastosowań
    2. Zastosowanie programowania matematycznego we współczesnych zestawach narzędzi programistycznych
    3. Przegląd bibliotek i solwerów
    4. Programowanie liniowe całkowitoliczbowe
    5. Programowanie liniowe mieszane
    6. Programowanie nieliniowe całkowitoliczbowe
    7. Programowanie nieliniowe mieszane
    8. Zastosowania biblioteki pyomo w programowaniu matematycznym
4. Metaheurystyki
    1. Zastosowania metaheurystyk w optymalizacji
    2. Algorytmy ewolucyjne i genetyczne
    3. Ogólny flow algorytmów genetycznych
    4. operatory: selekcja, krzyżowanie, mutacja
    5. Zastosowania biblioteki PyGAD w optymalizacji genetycznej
5. Optymalizacja gradientowa
    1. Definicja i zakres zastosowań 
    2. Problem ekstremów globalnych i lokalnych
    3. Pojęcie gradientu funkcji
    4. Symulacja optymalizacji gradientowej w różnych wariantach szybkości 
    5. Zastosowania optymalizacji gradientowej
6. Uczenie maszynowe
    1. Definicja i problematyka rozwiązywana przez uczenie maszynowe
    2. Rodzaje uczenia maszynowego
    3. Definicja uczenia nadzorowanego
    4. Regresory uczone metodą optymalizacji gradientowej: regresja liniowa wraz z regularyzacją
    5. Klasyfikatory uczone metodą optymalizacji gradientowej: regresja logistyczna wraz z regularyzacją
    6. Zastosowania praktyczne uczenia maszynowego z wykorzystaniem biblioteki scikit-learn
7. Przetwarzanie wstępne danych
    1. Problem danych „nieczystych”
    2. Potrzeba wstępnego przetwarzania danych dla ustabilizowania procesu treningu
    3. Metody podziału danych przez rozpoczęciem treningu i oceny modeli
    4. Obsługa missing values w zbiorach danych
    5. Skalowanie i transformacja wartości atrybutów w zbiorach danych, w tym transformacja rozkładów prawdopodobieństwa do postaci gaussowskiej
    6. Potoki transformujące dane w bibliotece scikit-learn
8. Wiedza niepewna
    1. Pojecie wiedzy niepewnej
    2. Zbiory rozmyte
    3. Logika rozmyta
    4. Reguły decyzyjne
    5. Klasyfikacja wiedzy niepewnej z wykorzystaniem biblioteki skfuzzy
    6. Przykład zastosowania w optymalizacji procesu produkcji paliw
